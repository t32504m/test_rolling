# 決定の記録

研究と開発で、オーナーが決めたこと・承認したことの記録。論文を書くときに「なぜそうしたか」を確かめる元にする。
新しい決定は、日付と理由を付けて下に足す。詳しい経緯は、括弧内の Issue・PR・文書を見る。

参加者のデータに関わることは、ここに書かない（`private/` の扱いは CLAUDE.md のとおり）。

## ソルバー（RQ1）

| 日付 | 決定 | 理由・補足 |
| --- | --- | --- |
| 2026-10 | 栄養制約付きの献立問題（diet problem）を、整数計画法で解く（PuLP＋CBC） | 同じ入力からは同じ結果を返す（実験の再現性） |
| 2026-10 | 常識的でない結果（野菜ジュース52本など）を、絶対数の上限ではなく、世帯の規模に比例する制約で防ぐ | 1人1日あたりの量、エネルギーに占める割合、品目の多様性 |
| 2026-10-22 | たんぱく質の値がない品目は 0g とみなして計算する | 「目標以上」の判定なので安全側になる |
| 2026-10-22 | 品目の kcal などは、代表商品の公式表示を正とする | 例：カップヌードルは日清の表示（#8、PR #10） |
| 2026-10-22 | 世帯の区分を東京備蓄ナビにそろえる：大人／子供（3歳〜小6、大人の0.8倍）／乳幼児（普通の食事に数えず、ミルクなどの特別食だけ） | 以前は子供を全員乳児として数え、液体ミルク63本などを出していた（#11、PR #15） |
| 2026-10-22 | 子供と乳幼児の水は、大人の0.8倍（2.4 L/日） | 東京備蓄ナビと同じ |
| 2026-10-22 | 量の土台を食事の回数にする（1人1日3食。主食・主菜は1食に1食分）。超える場合は理由を出す | 以前は主食が食事の回数より多かった（27食に対して33食）。各品目の数に根拠の説明を付ける（#11、PR #15） |
| 2026-11-05 | エネルギーの目標（大人 2,000 kcal/日）は据え置き、根拠の記述を正しく直す | 公的な備蓄リストの例の範囲に収まる。農林水産省の例（大人2人・7日）は主食と主菜だけで 1人1日 2,186〜2,482 kcal（PR #18） |
| 2026-11-05 | エネルギーの不足は、間食ではなく主食で補う。主食は1食に最大2食分（1食分を超えた分は理由つき）、主菜は1食に1食分まで | 不足をようかんなどの間食で埋めていた（「毎食ようかんはきつい」）。農林水産省の例の主食は、品目マスタに当てはめると1人1日 約6食分（#20） |
| 2026-10-22 | 購入単位（pack_size）は「代表商品を、一般的な店で買うときの最小の単位」とし、出典を付ける | 「ようかん5本」は参照した商品が5本入りだっただけで、普通は1本で買える（#12、PR #16） |
| 2026-10-22 | ようかんの代表商品を「井村屋 58gミニようかん 煉」（1本売り）にする | 同上 |
| 2026-11-05 | 乳幼児がいる世帯には、テンプレートにかかわらず、ミルクなどの乳幼児向けの品目を出す | 「乳幼児がいれば、ミルクを足すというより、テンプレートが baby に変わるのではないか」（オーナー）。東京備蓄ナビも必ず出す |

## 画面と印刷物（RQ2・RQ3）

| 日付 | 決定 | 理由・補足 |

| 2026-10-22 | 不要なセカンダリラベルや説明を書かない。レイアウトに説明させる | 文字で説明してしまう AI の出力を防ぐ（CLAUDE.md「画面と印刷物の原則」） |
| 2026-10-22 | 商品の写真や画像は、リポジトリに入れない | 著作権。リポジトリは public。印刷物の絵をどうするかは、印刷ページを作るときに決める |
| 2026-10-22 | 子供の係数を 0.8 にそろえる（calender.html の 0.6 を直す） | 未対応 |
| 2026-11-05 | ソルバーの出力から各月の消費の割り振りを決め、カレンダーに出力する | 実験の A・B は、どちらもこのカレンダーの上に作る |
| 2026-11-12 | 1日に食べる量は「一人一品・二品まで」とし、収まらない分は消費日を増やす（小さい世帯は月1日、大きい世帯は月2〜3日） | 大人4・子供3・乳幼児1・7日分では、月1日だと食べ物だけで毎月34〜36個になり、「一品・二品を足す」にならない（PR #23 の常識のレビュー）。研究の主張を世帯の規模にかかわらず守るため（案A） |
| 2026-11-12 | 割り振りの約束を強める：毎月、主食か主菜を1個以上、水以外の食べ物を2個以上（月ごとの個数の差は1個以内のまま） | PR #23 の常識のレビューで「おかゆと水だけ」「主菜がない」月が見つかった。例（大人1・3日・高齢者向け）を見て、オーナーが「強めたものの方が自然」と承認 |
| 2026-11-12 | 乳児用の品目も、ほかの品目と同じく12か月で回し、普段の授乳で使う形にする。※同日、液体ミルクの賞味期限が10〜15か月（docs/reference_infant_milk.md）で12か月の周期と合わないと分かり、同日に下の決定で改めた | 統括の提案をオーナーが承認。「ミルクは家族全員で消費するわけではない」点が、テンプレートとの違い（オーナー）。ミルクの備蓄品としての実態は、出典つきで調べる |
| 2026-11-12 | 乳児用のミルクは、世帯の備蓄日数が短くても少なくとも14日分を備える。乳児用の品目は12か月の割り振りから外し、普段の授乳で使った分を買い足す | 「農林水産省に従うべき。乳児用品は特別」（オーナー）。農林水産省の要配慮者向けガイドは「少なくとも2週間分」を推奨。液体ミルクの賞味期限は10〜15か月で、12か月の周期と合わない（docs/reference_infant_milk.md）。閾値は tests/sanity_config.json の infant.min_days |
| 2026-11-13 | 乳幼児は月齢で分けず、一律に扱う（液体ミルク1日3本、ベビーフード1日2食を14日分） | オーナー決定。東京備蓄ナビも乳幼児をひとまとめにしている。月齢に合わない品目が出ることは、論文の限界として書く。哺乳瓶は「食料と水のみ」の範囲外なので扱わない（限界に書く） |
