# 決定の記録

研究と開発で、オーナーが決めたこと・承認したことの記録。論文を書くときに「なぜそうしたか」を確かめる元にする。
新しい決定は、日付と理由を付けて下に足す。詳しい経緯は、括弧内の Issue・PR・文書を見る。

参加者のデータに関わることは、ここに書かない（`private/` の扱いは CLAUDE.md のとおり）。

## 比較の対象（RQ1）

| 日付 | 決定 | 理由・補足 |

| 2026-10-22 | 比較の対象を、防災ニッポンの計算ページから東京備蓄ナビに変える | 防災ニッポンの計算ページ（ipoh.jp/stock）が閉鎖されていた。計算方法は `docs/tokyo_bichiku_navi.md` に出典つきで記録（#3） |
| 2026-10-22 | 東京備蓄ナビの計算を Python で再現し、公開サイトの出力と照合する | 比べるための道具であり、再現そのものは目的ではない（#13、PR #14） |
| 2026-10-22 | 東京備蓄ナビの世帯の人数には、乳幼児を含める | 公開ソースコード（`result.vue` の `family.length`）で確認（PR #14 のレビュー） |
| 2026-11-05 | 東京備蓄ナビとソルバーの比較を一度行った（11/7 の判断点の条件） | `reports/compare_tokyo.md`（PR #19）。東京は大人換算 1人1日 2,921〜4,161 kcal（計算に入れられた品目だけの下限。主食の重なりが主な理由）。ソルバーは目標どおり約 2,000 kcal。テンプレートを固定すると、ソルバーも世帯の規模では品目の構成がほとんど変わらない |

## ソルバー（RQ1）

| 日付 | 決定 | 理由・補足 |
| --- | --- | --- |
| 2026-10 | 栄養制約付きの献立問題（diet problem）を、整数計画法で解く（PuLP＋CBC） | 同じ入力からは同じ結果を返す（実験の再現性） |
| 2026-10 | 常識的でない結果（野菜ジュース52本など）を、絶対数の上限ではなく、世帯の規模に比例する制約で防ぐ | 1人1日あたりの量、エネルギーに占める割合、品目の多様性 |
| 2026-10-22 | たんぱく質の値がない品目は 0g とみなして計算する | 「目標以上」の判定なので安全側になる |
| 2026-10-22 | 品目の kcal などは、代表商品の公式表示を正とする | 例：カップヌードルは日清の表示（#8、PR #10） |
| 2026-10-22 | 世帯の区分を東京備蓄ナビにそろえる：大人／子供（3歳〜小6、大人の0.8倍）／乳幼児（普通の食事に数えず、ミルクなどの特別食だけ） | 以前は子供を全員乳児として数え、液体ミルク63本などを出していた（#11、PR #15） |
| 2026-10-22 | 子供と乳幼児の水は、大人の0.8倍（2.4 L/日） | 東京備蓄ナビと同じ |
| 2026-10-22 | 量の土台を食事の回数にする（1人1日3食。主食・主菜は1食に1食分）。超える場合は理由を出す | 以前は主食が食事の回数より多かった（27食に対して33食）。各品目の数に根拠の説明を付ける（#11、PR #15） |
| 2026-10-22 | 購入単位（pack_size）は「代表商品を、一般的な店で買うときの最小の単位」とし、出典を付ける | 「ようかん5本」は参照した商品が5本入りだっただけで、普通は1本で買える（#12、PR #16） |
| 2026-10-22 | ようかんの代表商品を「井村屋 58gミニようかん 煉」（1本売り）にする | 同上 |

## 未決（オーナーの判断待ち）

| 起票 | 論点 | 現状 |
| --- | --- | --- |
| 2026-10-22 | エネルギーの目標（大人 2,000 kcal/日）を見直すか | 出典は厚生労働省の事務連絡（平成23年4月21日）。避難所の食事提供の計画のための値で、期間は被災後約3か月まで。1歳以上の平均で、ほぼ平時の必要量。家庭の備蓄の値ではない。子供をさらに0.8倍しているので二重の調整になっている。公的な備蓄リストの例を #17（PR #18、`docs/reference_stock_lists.md`）で計算した：農林水産省の例（大人2人・7日）は主食と主菜だけで 1人1日 2,186〜2,482 kcal、うち主食 1,749 kcal。統括の提案は「2,000 kcal は据え置き、根拠の記述を直し、不足は主食で埋める（案A）」 |
| 2026-10-22 | 標準テンプレートで、食事の回数を超える主食の追加をどこまで認めるか | 上の目標と連動する。PR #16 と組み合わせると、大人4人・7日で主食2食分の超過が出る |
