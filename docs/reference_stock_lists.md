# 公的な家庭の備蓄リストの例と、1人1日あたりのエネルギー（Issue #17）

ソルバーのエネルギーの目標（大人 2,000 kcal/日）を判断するための材料として、公的機関などが示す
**家庭の備蓄リストの例**を集め、品目マスタ（`data/items-master.json`）の品目に当てはめて、
1人1日あたりのエネルギーとたんぱく質を計算した。目標を変えるかどうかの提案はしない。

- データ：`data/reference_stock_lists.json`（原文の品目と数量、出典、当てはめ）
- 計算：`python3 scripts/reference_energy.py`（`--json` で計算結果を JSON で出す）
- 閲覧日：すべて 2026-10-22

### 1.1 エネルギーやたんぱく質の値が書かれていたもの

愛知県瀬戸保健所の資料だけに、値が書かれていた。管理栄養士が自宅の備蓄から作った2日分の献立の値である（原文）。

> 1日目 エネルギー 1,608kcal タンパク質 54.9ｇ 食物繊維 12.２ｇ
> ２日目 エネルギー 1,970kcal タンパク質 43.7ｇ 食物繊維 22.8ｇ

品目ごとの数量が書かれていないので、品目マスタでの再計算はしていない。
ほかのリストには、エネルギーやカロリーの目標の記載はなかった。

### 1.2 数量の計算ができなかったリストの要点（原文）

- 農林水産省（要配慮者向け）：「飲料水として、1人当たり1日1リットルの水が必要です。調理等に使用する水を含めると、3リットル程度あれば安心です。」「平時から少なくとも2週間分を備蓄することが推奨されます。」主食は「精米、レトルトご飯、乾麺、カップ麺、小麦粉、シリアル類 等」、主菜・副菜は「缶詰、レトルト食品、フリーズドライ食品、乾物、日持ちする野菜等」。
- 農林水産省（単身者向け）：水は「1人1日およそ3ℓ程度（飲料水＋調理用水）」、カセットボンベは「3本 ※1人1日1本程度」。食品は品目の例だけ。
- 首相官邸：「飲料水 3日分（1人1日3リットルが目安）」「非常食 3日分の食料として、ご飯（アルファ米など）、缶詰、干物、乾パンなど」「大規模災害発生時には、「1週間分」の備蓄が望ましいとされています。」出典として政府広報オンライン「災害に備えた家庭備蓄のポイント」を表示している。
- 静岡県：「1週間の目安（1人） 飲料水／1日3L×7日＝21L 食料品／1日3食×7日＝21食」。
- 日本栄養士会：「家庭の食料備蓄として、最低３日分、できれば１週間分の食料品・飲料水・日用品等の確保について（中略）普及啓発を行う。」参考資料として農林水産省の食品ストックガイドを挙げる。
- 石川県：出典に農林水産省「家庭備蓄ポータル」を挙げ、PDF 1〜2ページの「大人２人／１週間分の家庭備蓄の例」の数量は、農林水産省の例と同じだった（画像で照合）。
- 三条市：引用元に農林水産省のガイドを挙げる。食品の数量は農林水産省の例のちょうど半分（米2kg・1袋、そうめん1袋、パスタ1袋、カップ麺類3個、パックご飯3個、レトルト食品9個、パスタソースなど3個、缶詰(肉･魚)9個）。水だけは「２L×11本」で、農林水産省の1人分（12本）と異なる。

## 2. 品目マスタへの当てはめ方

各項目を、次の三つのどれかに分けた（JSON の `map.tier`）。

| 扱い | 条件 |
| --- | --- |
| 確定（confirmed） | 原文に重さがある（米 2kg など。マスタの `unit_gram` で割って換算）。または、原文が容器の個数か食数で、マスタの品目名が原文の品目を含み、マスタの数え方も同じ（パックご飯6個 → S004 6食、即席みそ汁10食 → V006 10食 など） |
| 参考（reference） | 当てはめに、出典のない仮定が入る。原文の「食」をマスタの1袋・1本・1缶に読み替えるもの（マスタの `units_per_serving` は設計上の値で、出典がない）、内訳が分からないもの、原文の品目がマスタになく近い品目で代用したもの、「ミニ」などで大きさが違うもの |
| 外す（excluded） | 数量がない（適宜・適量）、マスタに対応する品目がない、1パック・1箱の中身が分からない、水 |

- 候補の品目が複数ある項目（「レトルト食品」「缶詰（肉・魚）」など）は、kcal が最小になる当てはめと最大になる当てはめの両方を計算し、範囲で示す。
- 原文に1個の大きさがない項目は、マスタの代表商品の大きさと栄養値で計算した。
- 1人1日あたりの値は、合計を「大人の人数 × 日数」で割った。集めたリストはすべて大人だけなので、子供の係数は使っていない。
- 主食・主菜・副菜・間食は、マスタの `meal_role`（staple / main / side / snack）で分けた。
- たんぱく質の値がマスタにない品目（M006、N002、S007、V010）は 0g として足した。そのため、それらを含む当てはめのたんぱく質は、実際より小さい。

### 3.1 数値の内訳の確認（手計算）

- maff-general の主食 1,749 kcal：米 4,000g ÷ 150g × 534 kcal ＝ 14,240、乾麺 1,800g ÷ 100g × 350 ＝ 6,300、カップ麺 6 × 364 ＝ 2,184、パックご飯 6 × 294 ＝ 1,764。合計 24,488 kcal ÷（2人 × 7日）＝ 1,749 kcal。
  主菜は、レトルト食品 18個・パスタソース 6個・缶詰 18缶で、437（カレー・焼き鳥缶の場合）〜733 kcal（ハンバーグ・サバ缶の場合）。副菜・間食は数量が「適宜」なので 0。
- iwaizumi-town の主食 2,839 kcal：米 約333g/日（1,187 kcal）、パックご飯 2個/日（588）、カップ麺 1個/日（364）、乾麺 200g/日（700）。原文の表で、これらは別々の行として足し合わされている。
- tokyo-navi-1a-3d の主食 3,255 kcal：レトルトご飯 3食/日（882 kcal）と無洗米が別々に足される。無洗米は ceil(0.375kg × 3日) ＝ 2kg に切り上げられるので、1日あたり 約667g（2,373 kcal）になる。7日分の tokyo-navi-2a-7d では 6kg ÷ 14 ＝ 約429g/日（1,526 kcal）。
- kochi-city は、マスタに対応のないレトルトの惣菜・汁物（12品目）と、大豆プロテインバー・イオン飲料を外しているので、実際の値はこれより大きい。
- kyoto-city は、数量の多くが「食」で書かれているので、確定分は小さく（359〜392 kcal）、「確定＋参考」で 1,343〜1,522 kcal になる。「レトルトパスタ：1食」「加水等不要な食料：2食」は外している。

## 4. 分からなかった点（不明）

1. **政府広報オンライン**（https://www.gov-online.go.jp/article/202103/entry-10236.html ほか）は、curl と WebFetch のどちらも HTTP 403 で拒否された。回避はしていないので、内容は不明。首相官邸のページが出典として挙げている「災害に備えた家庭備蓄のポイント」の本文も確認できていない。
2. **内閣府の防災のページ**（bousai.go.jp）で、品目と数量のある家庭の備蓄リストは見つからなかった。
3. **日本栄養士会**の資料で、品目と数量のある家庭の備蓄リストは見つからなかった（ガイドは「最低３日分、できれば１週間分」と、農林水産省のガイドの紹介だけ）。
4. **1個・1袋・1缶の大きさ**：原文に重さがない項目（カップ麺、パックご飯、果物缶詰、ミックスナッツ、ウエハース、ふりかけ など）は、マスタの代表商品の値で計算した。原文の商品の大きさは不明。特に、果物缶詰はマスタの代表商品が 425g（320 kcal）と大きい。
5. **「食」からマスタの単位への換算**：京都市の「パン：1食」「レトルト食品：２食」「野菜ジュース：3食」「ビスケット等：3食」など、岩泉町の「レトルト食品 ６食」は、1食がマスタの1袋・1本・1缶に当たるという根拠が見つからない。「参考」として計算した。
6. **内訳**：「レトルト食品（牛丼の素、カレー等）」「缶詰（肉・魚）」「主菜用缶詰（肉、野菜、豆、魚）」「果物缶詰、ジュース」などの内訳は、どの資料にも書かれていない。範囲で示した。
7. **マスタにない品目**：野菜の缶詰、パウチスープ、いわしの缶詰、レトルトパスタ、レトルトの惣菜（ハヤシ、チキンのトマト煮、肉じゃが、おでん など）、汁物（豚汁、けんちん汁 など）、大豆プロテインバー、イオン飲料、健康飲料粉末、チーズ・プロテインバー。近い品目で代用したもの（野菜の缶詰 → V010、いわし → 魚缶詰3品目）は「参考」、それ以外は外した。
8. **東京備蓄ナビの「箱」「パック」**：栄養補助食品（箱）、乾麺 即席麺（パック）、お菓子（パック）、飲み物（本）の中身と大きさは、サイトにもソースコードにも書かれていない（`docs/tokyo_bichiku_navi.md` の 6 章も参照）。
9. **米と無洗米**：農林水産省・岩泉町の「米」を、マスタの無洗米 S010（1合150g 534 kcal）で重さ換算した。精白米と無洗米で 1g あたりの値が同じかどうかは確かめていない。
10. **たんぱく質**：M006（レトルトカレー）、N002（ゼリー飲料）、S007（ロングライフパン）、V010（野菜スープ缶）はマスタにたんぱく質の値がなく、0g として足した。
11. **兵庫県**のページの「家庭備蓄の一例」は、農林水産省の例を画像で載せている。画像の中身は照合していない。
12. **京都市・高知市の資料の発行日**は、文書に書かれていない（PDF の作成日だけを記録した）。
